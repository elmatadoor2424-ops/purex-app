# PureX Cleaning Services Platform (CyberX Framework)

منظومة **PureX** الرقمية المتكاملة لخدمات النظافة والتعقيم الفندقي الفاخر للشقق والفلل والمقرات الإدارية بأعلى معايير الأمان والخصوصية.

---

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Framework:** Next.js 16 (App Router, Server Actions, TypeScript)
- **Styling & UI:** Tailwind CSS v4, Vanilla CSS Design System, Cairo & Geist Typography
- **Micro-interactions:** Framer Motion
- **Icons:** Lucide React Icons
- **Integrations:** WapiPilot WhatsApp API Webhook Route (`/api/booking`)
- **Hosting & CI/CD:** جاهز للنشر الفوري على Vercel و GitHub

---

## 🌟 الميزات والمكونات الأساسية (Core Features)

### 1. الصفحة الرئيسية والهيرو سكشن (`src/app/page.tsx`)
- تصميم نيون مينيماليست حديث وفاخر متناسق مع هوية **CyberX**.
- عرض القيمة الفندقية: *"خدمات نظافة فندقية للشقق والفلل بأعلى معايير الأمان والاحترافية"*.
- **حاسبة الأسعار التفاعلية والذكية (`PricingCalculator.tsx`):**
  - اختيار نوع العقار (شقة سكنية، فيلا مستقلة، ما بعد التشطيب، مقرات إدارية).
  - شريط تمرير مساحة العقار بالمتر المربع (Area Slider).
  - محدد عدد الغرف ودورات المياه.
  - باقات التعقيم الإضافية الفورية (بخار جاف 180°C، غسيل كنب بالرغوة الألمانية، جلي وتلميع رخام وكريستال، تعقيم أوزون ونانو).
  - حساب لحظي للتكلفة الإجمالية وقيمة العربون المطلوب مع خصم الحجز الذاتي 10%.
- جدول مقارنة تفصيلي بين معايير النظافة التقليدية ومعايير **PureX** الفندقية.

### 2. نموذج الحجز وسداد العربون (`src/components/BookingModal.tsx`)
- نموذج متدرج (Multi-step Modal Form):
  1. **بيانات العميل:** الاسم، رقم الهاتف والواتساب، المنطقة، اسم الكمبوند أو البرج.
  2. **الموعد والفترة الزمنية:** تاريخ الخدمة، واختيار الفترة (صباحية 9ص أو مسائية 2م).
  3. **خيارات سداد العربون:**
     - **فودافون كاش (Vodafone Cash):** رقم الحساب مع زر نسخ فوري وتعليمات التحويل.
     - **إنستا باي (InstaPay):** معرّف الدفع اللحظي بدون رسوم إضافية.
     - **Binance USDT:** عنوان محفظة TRC-20 لعملاء العملات الرقمية.
  4. **إثبات التحويل:** إدخال رقم العملية (Reference ID) أو رفع صورة إشعار التحويل لتثبيت الموعد.
  5. **شاشة التأكيد:** توليد كود حجز مرجعي وتوجيه فوري لمحادثة الواتساب.

### 3. الربط البرمجي مع منصة WapiPilot (`src/app/api/booking/route.ts`)
- مسار API آمن يستقبل طلبات الحجز ويتحقق من سلامة البيانات:
  - إرسال Payload منظم بصيغة JSON إلى Webhook منصة **WapiPilot** لإرسال رسائل التأكيد التلقائية للعميل فوراً عبر WhatsApp.
  - حفظ وتتبع الحجوزات داخل الذاكرة وقاعدة البيانات التشغيلية.

### 4. لوحة تحكم العمليات والإدارة - لـ "دنيا" (`src/app/admin/operations/page.tsx`)
- حماية بكلمة مرور إدارية سريعة (Passcode: `purex2026` أو `donia`).
- إحصائيات فورية (KPIs) لعدد الحجوزات، العربونات المحصلة، وحالات الطلبات.
- شارات الحالة الملونة: `[بانتظار العربون]`، `[مؤكد ومجدول]`، `[جاري التنفيذ بالموقع]`، `[مكتمل ومسلّم بالمحضر]`.
- أزرار اتصال سريع ورسائل واتساب مباشرة للعملاء.
- **محضر المعاينة والاستلام الرقمي (Digital Inspection Checklist):**
  - فحص وحصر الأثاث، التحف، والأجهزة الحساسة قبل البدء.
  - توثيق الخدوش أو التلفيات السابقة لإخلاء مسؤولية الطاقم.
  - فحص بنود النظافة الفندقية بعد الخدمة (مطابق ✓ أو ملاحظة ⚠).
  - لوحة توقيع إلكتروني حي (Digital Signature Canvas) للعميل أو المشرف.
  - تقييم العميل بالنجوم (1 إلى 5 نجوم).

## 🛠️ التشغيل المحلي (Local Development)

```bash
# الانتقال لمجلد المشروع
cd purex-app

# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# تشغيل خادم التطوير
npm run dev
```

التطبيق متاح الآن عبر:
- **الموقع الرئيسي:** [http://localhost:3000](http://localhost:3000)
- **بوابة تسجيل العاملات والتحقق من الهوية:** [http://localhost:3000/workers/register](http://localhost:3000/workers/register)
- **لوحة العمليات المشتركة (دنيا وأحمد):** [http://localhost:3000/admin/operations](http://localhost:3000/admin/operations)
  *(كلمات المرور المعتمدة: `purex2026` أو `ahmed` أو `donia`)*
- **API الحجز وإشعارات الواتساب:** `http://localhost:3000/api/booking`
- **API العاملات والتحقق:** `http://localhost:3000/api/workers`

## 🌐 النشر والربط مع Vercel و GitHub

1. تهيئة مستودع Git:
```bash
git init
git add .
git commit -m "feat: complete CyberX PureX production platform"
git branch -M main
```

2. الربط مع GitHub:
```bash
git remote add origin https://github.com/<your-username>/cyberx-purex.git
git push -u origin main
```

3. الربط مع Vercel:
- الدخول إلى لوحة تحكم [Vercel](https://vercel.com).
- اختيار مستودع `cyberx-purex`.
- إضافة المتغيرات البيئية من ملف `.env.example`:
  - `WAPIPILOT_WEBHOOK_URL`
  - `WAPIPILOT_API_KEY`
  - `ADMIN_PASSCODE`
- الضغط على **Deploy**.
